# 🟠 Itaú — Experiência Digital

Projeto de desenvolvimento web inspirado na identidade visual e na experiência digital do banco Itaú, criado para fins educacionais e composição de portfólio.

🌐 **Acesse o projeto:** [itau-delta.vercel.app](https://itau-delta.vercel.app/)

## 📌 Sobre o projeto

O objetivo deste projeto foi desenvolver uma landing page inspirada no universo digital do Itaú, explorando uma interface moderna, organizada e intuitiva.

A página apresenta diferentes serviços financeiros, incluindo cartões, investimentos, conta digital, benefícios e funcionalidades do aplicativo.

O desenvolvimento teve como foco a construção visual, organização dos elementos e experiência de navegação.

## ✨ Funcionalidades e seções

- Página inicial com apresentação dos serviços.
- Seção de cartões de crédito.
- Apresentação de investimentos.
- Área de conta digital.
- Seção de vantagens e benefícios.
- Apresentação dos recursos do aplicativo.
- Área de serviços financeiros.
- Botões de navegação e chamadas para ação.

## 🎨 Design

- Identidade visual inspirada no Itaú.
- Interface moderna e minimalista.
- Organização de conteúdo por seções.
- Destaque para elementos visuais e chamadas para ação.
